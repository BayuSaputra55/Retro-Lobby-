03 / QUICK START

Cara mulai mabar Quetzal

⌁
01

Siapkan game

Kedua pemain perlu versi Pokémon Quetzal yang sama dan salinan game/save masing-masing. Jangan bagikan file game berhak cipta secara publik.

02

Siapkan RetroArch

Pasang RetroArch di HP dan PC. Ikuti panduan Quetzal untuk konfigurasi core gpSP, nama pemain, dan Netplay.

03

Buat sesi Netplay

Host aktifkan relay dan password sesuai panduan. Teman mencari room host di RetroArch lalu bergabung.

04

Masuk ke MPLAYER

Di area luar ruangan, buka Start → COOP/MPLAYER → 2J/2P. Untuk tukar pilih Trade Center; untuk bertarung pilih Colosseum.

⚠ Batasan penting: website ini saat ini hanya prototype lobby. Fitur invite code belum menghubungkan dua perangkat. Multiplayer sungguhan ditangani RetroArch Netplay; kualitas koneksi tergantung jaringan, relay, dan konfigurasi pemain.
